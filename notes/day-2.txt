Types of Angular app:
--------------------------
1. Modular:

Command to create Modular Angular app: ng new <app-name> --standalone=false

Module class example:

@NgModule({
	//registering components, directives, pipes
	declarations:[AppComponent, AppPipe, AppDirective],

	//register services here
	providers:[AppService],

	//import built-in and application feature modules
	imports:[BrowserModule, OrderModule],

	//mention the name of registered components, pipes, directives, modules that can be exported to another module by 	importing this module
	exports:[AppComponent],

	//which component(s) is/are bootstrapped by default when the module is pulled
	bootstrap:[AppComponent]
})
export class AppModule{
}

2. Non-modular/Standalone Angular app:
--------------------------------------------
Command to create Non-modular Angular app: ng new <app-name> [--standalone=true]
Note: directly import pipe, directive or register services in the component itself

Example: 
@Component({
	//import other component, pipe, directive or modules here
	imports:[OtherComponent, OtherPipe, OtherDirective],

	//register services here
	providers: [OtherService]
})
export class App{
}

Service and Dependency Injection:
-----------------------------------------
service: a place to write common business/ data acces logic etc.
1. create a service class with necessary methods and data
	for loose coupling use interface as contract for service

2. register service provider
3. consume the service -> using constructor injection or using "inject()" method

1. create service
2. register a provider for the service and consume the service
	
	a provider object holds metadata of something that needs to be dependency injected

	properties:
	i. provide -> for assigning token value
	ii. useX -> what to be dependency injected
		- useClass: type of class whose instance has to be DIed
		- useValue: value to be DIed
		- useExisting: almost similar to useClass
		- useFactory: a factory function which will return the item to be DIed

	types of providers:
	a. ClassProvider [provide, useClass]
	b. ValueProvider [provide, useValue]
	c. ExistingProvider [provide, useExisting]
	d. FactoryProvider [provide, useFactory]

	base type of all -> Provider
	
	place: use 'providers' property at
		a. component level -> deciated instance for every instance of the component
		b. global (app.config.ts file) -> deciated singleton instance for entire app

	provider: 

	1. class name is used as token 
------------------------------------------------------
	const provider:Provider ={
		provide: CalculationService
		useClass: CalculationService
	}

	register: providers:[provider] or providers:[CalculationService]

	consume:
	private svcRef: CalculationService;
	constructor(svc: CalculationService){
		this.svcRef = svc
	}

	or 
	private svcRef: CalculationService = inject(CalculationService)

	

	2. custom token 

	i. string token:
	const TOKEN ='TOKEN'
		
	ii. InjectionToken
	const TOKEN = new InjectionToken<ServiceContract>('TOKEN')

	provider:
	const provider:Provider ={
		provide: TOKEN
		useClass: CalculationService

	}

	registration:
	providers:[provider]

	consume:
	private svcRef: ServiceContract;
	constructor(@Inject(TOKEN) svc: ServiceContract){
		this.svcRef = svc; 
	}

	or 
	private svcRef: ServiceContract = inject<ServiceContract>(TOKEN)


	const SECRET_KEY_TOKEN ='SECRET_KEY_TOKEN'
